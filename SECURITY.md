# Security

Report a VaultVision security issue privately to
<security@vaultvision.tech>.

Include the affected endpoint, reproduction steps, observed impact, and a
safe proof of concept. Do not access data that is not yours, move funds,
degrade production, publish an unpatched issue, or include wallet secrets.

The public MCP server is intentionally read-only. A tool that connects a
wallet, requests a signature, places a trade, submits a deposit or withdrawal,
or moves funds would be outside its documented security boundary.
